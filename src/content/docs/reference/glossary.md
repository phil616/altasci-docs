## 业务术语

| 术语 | 本站示例中的含义 |
| --- | --- |
| 工作空间 | 团队资源与协作范围的逻辑空间 |
| 项目 | 围绕同一目标组织的资源与记录 |
| 订单 | 一次申请及其配置、状态与交付记录 |
| 验收 | 确认结果满足预先约定的要求 |
| sandbox | 隔离的示例与验证环境 |
| request_id | 关联请求与排查记录的编号 |

以上业务定义为 Demo 约定，正式业务采用不同定义时应另行说明。

## PKI 术语入口

公钥、私钥、证书、CA 和信任锚的说明集中维护在 [PKI 基础概念](/docs/pki/overview/)，避免多处出现不同解释。

## 文档约定

- `DEMO-` 前缀表示示例标识。
- `example.test` 下的域名仅用于测试场景说明。
- 「示例控制台」指假设的操作界面，本站不包含该控制台。
- 错误代码采用大写英文加下划线，见 [错误代码总览](/docs/errors/overview/)。

## 维护建议

新增术语时优先复用已有名称，必要时补充缩写。具有固定技术含义的词，建议链接到相应概念文档或标准来源。
