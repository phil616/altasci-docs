## 适用范围

访问 AltasCI 服务时，如果请求无法完成，服务会返回一个包含错误代码的错误页面。错误代码用于快速识别问题、确认可能原因并选择处理方式。

错误代码是稳定的问题标识，不等同于 HTTP 状态码：同一个错误代码可能对应多个状态码，同一个状态码也可能对应不同的错误代码。排查时请同时记录两者。

本文记录服务实际返回的 `E001` 至 `E008`。接口演示使用的错误代码（如 `AUTH_TOKEN_EXPIRED`、`BUSINESS_STATE_CONFLICT`）采用另一套编号方式，见 [错误代码总览](/docs/errors/overview/)。

## 错误代码索引

| 错误代码 | 名称 | 类型 | HTTP 状态码 | 严重级别 |
| --- | --- | --- | --- | --- |
| `E001` | 未定义错误 | 系统异常 | `500` | 高 |
| `E002` | 资源不存在 | 资源异常 | `404` | 中 |
| `E003` | 资源已停用 | 资源状态异常 | `410` / `403` | 中 |
| `E004` | 不接受 IP 访问 | 请求异常 | `403` / `421` | 中 |
| `E005` | 证书未提供 | 安全认证异常 | `495` | 中 |
| `E006` | 证书校验失败 | 安全认证异常 | `496` | 中 |
| `E007` | 访问已被禁止 | 安全策略异常 | `403` | 高 |
| `E008` | 安全漏洞错误 | 安全漏洞 | `500` | 高 |

## 通用排查步骤

1. 确认请求地址、请求方法和资源标识符正确。
2. 刷新页面，排除临时网络或服务波动。
3. 记录错误代码、发生时间、完整 URL 和复现步骤。
4. 问题持续出现时，按 [提交支持请求](/docs/help/support/) 整理信息后再联系技术支持。

## E001 — 未定义错误

服务器遇到尚未归类的异常，请求无法完成。

**常见原因**

- 网络、DNS 或 TLS 故障
- 服务进程崩溃或运行时异常
- 数据库连接异常或事务阻塞
- 第三方服务超时
- 部署配置与预期不一致

**处理建议**

刷新页面后重试。如果问题持续出现，请记录错误发生时间、复现步骤和相关日志，并联系技术支持。

## E002 — 资源不存在

请求的资源不存在，或当前账户无法访问该资源。

**常见原因**

- URL、资源 ID、Slug 或 Key 错误
- 资源已被删除或迁移
- API 路径、版本或请求方法不正确
- 资源属于其他账户、团队或命名空间

**处理建议**

检查请求地址和资源标识符，确认当前账户拥有访问权限，并根据最新 API 文档核对接口路径与请求方法。

## E003 — 资源已停用

资源仍然存在，但当前已被停用，无法继续提供服务。

**常见原因**

- 功能或 API 版本下线
- 配额耗尽、试用到期或账单异常
- 管理员手动停用
- 安全或合规策略触发隔离
- 临时资源到期

**处理建议**

检查管理后台中的资源状态、操作记录、账户通知、配额和计费状态。确认停用原因消除后，再尝试重新启用资源。

## E004 — 不接受 IP 访问

服务仅接受通过已授权域名发起的请求，直接使用 IP 地址访问会被拒绝。

**常见原因**

- 请求地址直接使用 IP
- DNS 尚未配置或未生效
- 本地 hosts 记录错误
- 代理或负载均衡未正确传递 Host

**处理建议**

使用已授权域名访问，确认 DNS 解析正确，并检查代理、负载均衡及 Host 请求头配置。

## E005 — 证书未提供

服务器要求客户端提供证书进行双向 TLS（mTLS）认证，但客户端未发送任何证书。

**常见原因**

- 客户端未配置或未加载客户端证书
- 浏览器或工具未启用 mTLS
- 客户端证书已过期或被吊销
- 请求工具未正确传递客户端证书
- 网络代理或网关剥离了客户端证书

**处理建议**

确认客户端已安装并加载有效的客户端证书；检查浏览器或请求工具的 TLS 设置是否启用了客户端证书发送；如使用 API 客户端，请确认其正确配置了 mTLS 参数。公开下载的 CA 证书链见 [CA 证书下载](/docs/pki/downloads/)，客户端证书本身不在此列。

## E006 — 证书校验失败

客户端已提供证书，但服务器无法通过验证。证书可能无效、过期、被吊销或与当前请求的域名不匹配。

**常见原因**

- 客户端证书已过期
- 证书未被服务器信任的 CA 签发
- 证书域名或 Subject 与预期不符
- 证书已被吊销（CRL / OCSP 检查失败）
- 证书格式损坏或编码错误

**处理建议**

检查客户端证书的有效期和签发链是否完整；确认证书由服务器信任的 CA 签发；使用 openssl 工具验证证书状态；如证书确实有效但仍被拒绝，请联系技术支持。证书链构成与校验方式参阅 [CA 证书下载](/docs/pki/downloads/) 与 [PKI 基础概念](/docs/pki/overview/)。

## E007 — 访问已被禁止

当前请求的来源 IP 或网络因触发安全风控策略而被封禁，无法继续访问 AltasCI 服务。

**常见原因**

- 来源属于爬虫网络或大规模代理池
- 自动化脚本产生高频、持续性请求
- 来源 IP 位于已知僵尸网络或恶意流量段
- 访问行为异常，触发安全风控策略
- 违反服务条款的滥用行为

**处理建议**

停止使用爬虫、自动化脚本等工具发起请求；如网络经由共享出口、代理或 CDN 回源，切换为直接网络后重试；如确认为误封禁，提供错误发生时间、来源 IP、完整请求地址和 Request ID 后联系技术支持申诉。

## E008 — 安全漏洞错误

检测到安全漏洞，当前连接或原始内容的安全性已无法确认。该页面按设计不应当在任何请求中出现，看到它即意味着漏洞仍然存在。

**常见原因**

- SSL / TLS 证书无效、过期或与域名不匹配
- 证书链不完整，签发 CA 不受信任
- mTLS 客户端证书缺失或校验未通过
- 存在中间人攻击（MITM）或流量劫持迹象
- 连接被降级，敏感数据以明文传输
- 依赖、镜像或构建产物来源被篡改（供应链异常）

**处理建议**

立即停止在当前连接上提交任何凭据、密钥或个人敏感数据，并按以下顺序自检：

1. 核对 SSL / TLS 证书的有效期、域名匹配与完整证书链。
2. 确认 mTLS 客户端证书已正确签发并通过校验。
3. 检查代理、网关与 DNS 是否存在中间人劫持。
4. 核对依赖、镜像与构建产物的来源、版本与签名是否与预期一致。

如果自检后漏洞特征依然存在，请勿继续访问或重试，并立即提供错误发生时间、完整请求地址、Request ID 与相关证书信息后联系技术支持。

## 错误代码格式

错误代码统一使用 `E<NNN>` 格式：`E` 表示 Error，`NNN` 是三位数字编号。

- 错误代码用于问题定位，客户端仍应同时记录 HTTP 状态码。
- 同一现象可能由多个错误代码说明，请以页面实际显示为准。
- 已发布的错误代码不会改变含义，也不会重复分配。

## 联系技术支持

邮箱：support@altasci.com

提交问题时请尽量提供：

- 错误代码
- 错误发生时间和时区
- 完整请求地址及请求方法
- Request ID / Trace ID
- Console 和 Network 日志
- 可稳定复现问题的操作步骤

整理材料时请移除令牌、密码和私钥等敏感信息；证书类问题提供公开证书信息和错误现象即可，排查不需要发送私钥。详细模板见 [提交支持请求](/docs/help/support/)。
