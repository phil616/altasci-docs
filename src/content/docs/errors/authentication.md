## AUTH_TOKEN_EXPIRED

**示例 HTTP 状态：401。** 表示访问令牌已过期。

1. 检查请求是否使用当前环境的令牌。
2. 通过系统支持的登录或刷新流程获取新令牌。
3. 更新凭据后，重新发起需要的请求。

重复发送同一个过期令牌不会解决问题。凭据管理以实际身份服务为准。

## ACCESS_DENIED

**示例 HTTP 状态：403。** 表示当前身份缺少执行操作的权限。

1. 核对工作空间、项目与操作目标。
2. 检查账号的项目角色和授权范围。
3. 联系负责人确认是否需要调整授权。

权限未调整前，不建议持续重试相同请求。

## 响应示例

```json
{
  "code": "ACCESS_DENIED",
  "message": "当前账号没有修改此项目的权限",
  "request_id": "demo-request-002",
  "data": null
}
```

提交支持信息时保留代码与请求编号，移除完整令牌。其他错误见 [错误代码总览](/docs/errors/overview/)。
