## 准备资料

以下流程是内部测试环境的 Demo，审批与有效期由实际证书服务策略决定。

| 信息 | 示例 |
| --- | --- |
| 应用名称 | 内部演示服务 |
| 使用环境 | sandbox |
| 申请域名 | demo.example.test |
| 申请用途 | 测试应用服务身份 |
| 责任人 | demo-owner |

## 生成申请

在受控环境中生成密钥对，按服务要求生成证书签名请求（CSR）。私钥保留在受控环境中，不作为普通申请附件提交。申请前核对主体、域名与使用场景。

## 签发与部署

1. 完成实际流程要求的身份或申请权限审核。
2. 获取签发结果与所需中间证书。
3. 检查证书内容与申请是否一致。
4. 在测试环境部署，验证服务实际返回的证书。
5. 记录证书标识、到期时间与责任人。

## 更新证书

到期前按策略发起更新，并预留部署和验证窗口。更新后确认应用加载了新证书，客户端连接成功。提前天数、密钥轮换与审批规则由实际策略决定。

## 撤销与留档

证书不再使用或出现密钥泄露等情况时，按颁发机构流程申请撤销。撤销状态的获取与检查由实际协议和系统配置决定。

验证失败时参阅 [证书验证与排查](/docs/pki/verification/)。
