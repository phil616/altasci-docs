## 什么是 PKI

公钥基础设施（PKI）通过证书、信任配置和管理流程，帮助系统把公钥与特定主体关联起来。证书验证时需要结合信任锚、有效期、用途与其他约束判断是否接受。

## 核心术语

| 术语 | 含义 |
| --- | --- |
| 公钥 | 可提供给其他参与方的密钥部分 |
| 私钥 | 由持有者保护，用于相应密码操作的密钥部分 |
| 证书 | 包含主体、公钥等信息并由颁发者签名的数据结构 |
| CA | 证书颁发机构 |
| 信任锚 | 验证过程中预先信任的起点 |
| 证书链 | 连接目标证书与信任锚的证书路径 |
